About

A web browser in one C file. It tokenises the HTML, wraps words into lines, and draws them with the 8x8 font from font.h into the 320x200 canvas.

What it is built on

drivers.h
disk (kfread), network (knet_http_get), gfx, mouse and key ports
07b_network.h
the kernel NIC driver, DHCP, DNS and TCP
comp.h
toolbar buttons, URL box, scrollbar
font.h
glyph bitmaps

Limits

  • Files up to 48000 bytes
  • No images, CSS or scripts
  • http:// only: no TLS, so https sites cannot be opened
  • The desktop freezes while a page downloads
