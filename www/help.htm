Tips

  1. Click a link to follow it.
  2. Click the URL box, type a file name such as about, press Enter. The .htm / .html extension is optional.
  3. Type example.com or http://host:port/path to load a web page. Redirects are followed.
  4. Drag the scrollbar on the right.
